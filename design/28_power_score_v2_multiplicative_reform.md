## 0. 当前唯一公式（3.0）

```text
清群比 = 当前构筑有效清群容量 / 本关清群门槛
Boss比 = 当前构筑有效单体容量 / 本关Boss门槛
防线比 = 当前构筑有效防线容量 / 本关攻线门槛
R      = min(清群比, Boss比, 防线比)
玩家有效战力 = round(本关推荐战力 × R)
```

- UI 只显示一个“有效战力”（英文 `Effective Power`）：它明确表示当前构筑针对所选关卡合同的预计通关能力，会随关卡弱点、Boss、攻线门槛和选卡预算变化；不得再简称为看似关卡无关的“战力”。
- 不新增“输出战力 / 生存战力 / 局内战力”等概念；三轴只写入诊断明细。
- 玩家侧使用当前角色/装备等级、当前永久技能等级，以及本关卡牌预算的确定性预期成型。永久技能等级决定该卡首次拿到时的真实等级。
- 随机卡不当成必得收益。只有 `levels[].guaranteed_card_offers` 明确保底的卡可计入预期，且多个候选按较弱者保守折算。
- 推荐侧是固定关卡合同，不读取玩家存档。`clear_requirement.power_contract` 由工具生成，包含清群/Boss/防线门槛、运行时 Boss 权重与固定推荐值。
- Boss 容量按真实 Boss 列表、阶段减伤/闪避/再生、抗性/弱点与破甲折算；`runtime_bosses` 同时由战斗和离线模型读取。
- 防线容量单独读取角色 HP、护甲、减伤、屏障、减速与修复；输出再高也不能覆盖防线低于 1.0 的事实。
- 减速力场按运行时真实上限折算：Lv1~Lv5 为 `30% / 40% / 50% / 60% / 80%`，防线容量中的减速反演最多计到 `80%`；与战斗端最低 `20%` 移速严格同源。

## 0. 当前玩家合同（2026-08-13）

```
玩家战力 = 核心装备战力(当前角色/武器/护甲/芯片/宠物)
         × 技能乘区(同一投影器：当前武器 + 当前永久技能等级 + 本关选卡预算)
         × 本关元素克制乘区

普通推荐 = 固定参考核心(先锋 + 自动机枪 + 关卡 recommend_level + clear_requirement)
         × 技能乘区(同一投影器：自动机枪 + 空永久技能档案 + 本关选卡预算)

挑战推荐 = 普通推荐 × 1.5
```

- 推荐侧显式传入固定档案，禁止读取当前存档；同一关在任意角色、武器、等级和技能存档下数值相同。
- 玩家永久技能逐级升级后，玩家战力必须单调不下降；推荐战力不跟涨。
- 局内实际拿卡不改写结算战力。结果页单列真实 `本局选卡 X/Y`，避免再制造“终局战力”。
- 当前共享投影器落地后，`level_046` 普通推荐为 `292`，`level_099` 普通推荐为 `3099`；这是尺子同源后的数字换刻度，不改变敌人 HP、波次或通关难度。

## 1. 公式组成

### 1.1 核心战力——与 battle.gd 伤害管线同构的乘法结构

```
输出倍率 O = 角色攻击 × 武器DPS × 装备乘区 × 主动技乘区
    角色攻击   = (base_atk/100) × (1 + atk_growth×0.45×(角色等级-1)) × fire_rate_mod
    武器DPS    = (固有强度/4.0) × (1+0.08×(武器等级-1)) × (1+0.025×(武器等级-1))
                 固有强度 = _weapon_effective_dps()(含 f0463f63 修复的连锁/过载/焚烧/审判折算)
    装备乘区   = Π 芯片/宠物的 damage_mult / fire_rate_mult / element_damage_mult(按 value+level_growth 实值)
    主动技乘区 = 1 + uptime × (爆发倍率 − 1)
                 uptime = duration/cooldown,爆发倍率 = damage_mult × barrage_fire_rate_mult
                 全部从 characters.json active_skill 实值读取,含 sig_level_* 成长与
                 角色等级 0.52 主动轨成长(对齐 battle.gd:1883)
生存倍率 S = 护甲 hp_mult×(1+level_hp_growth×等级) × (1+护盾/反击折算) × 芯片/宠物 HP/减伤乘区
玩家战力 = K × (O^0.82 × S^0.28)^γ × 技能乘区(本关选卡投影) × 元素乘区
    技能乘区 = _skill_power_scale(_projected_run_skill_levels(...))(现有投影体系保留,
               当前永久技能基础等级作为玩家投影种子)
    0.82/0.28 攻防权重沿用 design/24 Phase 6 已标定值
```

K、γ 标定锚点:免费裸装 L1 ≈ 11(保持玩家熟悉的刻度起点);其余各点由公式自然生长,**不再**
向旧加法曲线对齐(换刻度是 Owner 决策②)。

### 1.2 本关元素乘区（直接属于唯一玩家战力）

```
元素乘区 = mob_share × elem_factor(武器元素 vs 本关 primary_weakness)
         + boss_share × elem_factor(武器元素 vs 本关 Boss 弱点/免疫表)
elem_factor = pow(实际伤害倍率, 0.82)
    实际伤害倍率 ∈ { weakness_mult=1.5, 1.0, resist_mult=0.5, immune_damage_floor=0.08 }
    全部从 economy.json / bosses.json 动态读取,不硬编码
mob_share / boss_share = 本关敌方总 HP 中小怪/Boss 占比,由工具预计算落表(§2)
```

### 1.3 推荐战力(本关)= 恰好能通关所需输出,代入同一把尺

```
推荐战力 = K × (required_O^0.82 × S_ref^0.28)^γ × 技能乘区_ref
    技能乘区_ref:与玩家侧完全相同的投影/效果函数；固定输入 autocannon + 空永久技能档案
                 + 本关 target_card_picks + primary_weakness
    required_O:难度模型解出的最小装备侧输出(§2),已归一到"免费裸装L1 的 O=1"基准
    S_ref:按节奏免费生存基线(无护甲,S=1.0——与 required_O 的求解假设一致)
挑战模式:沿用现行 recommended_power_mult 倍率(近似,文档明示)
```

**玩家界面只比较两个数字：战力 / 推荐。推荐是固定及格线，升级只推动玩家战力靠近或越过它。**

## 2. required_O 数据流(模型只在一处)

新工具 `tools/generate_clear_requirements.py`(复用 simulate_balance 的敌方 HP/刷怪时长/漏怪模型):

- 对每关解最小可通关 DPS:`required_D = max(D_timeout, D_leak)`
  - `D_timeout`:在 刷怪时长+阶段超时上限 内清完全部敌方 HP
  - `D_leak`:DPS 不足时漏怪比例上升(`leak_frac = clamp(1 − D/敌方HP流入速率, 基线漏怪率, 1)`),
    解 `总突破伤害 × leak_frac ≤ 基地HP(base_hp_ref × ARMOR_HP_MULT × Boss垫底)` 的临界 D
- 校准锚点(工具内断言,不满足即报错,禁止拍脑袋调参凑数):
  - level_099:required_O ≈ 满配免费构筑的 O(design/25"将将能过"合同的直接翻译)
  - level_013:required_O ≈ Owner 实测 1★惨胜构筑(角色1级+雷霆四件套1级)的 O 附近
  - 全 99 关:按节奏免费构筑的 O ≥ required_O(战役设计保证按节奏玩家能通关)
- 输出写入 `data/levels.json` 每关新增字段:
  `"clear_requirement": {"min_output": <float>, "mob_hp_share": <float>, "boss_hp_share": <float>, "boss_id": <string|null>}`
- 新校验 `tools/check_clear_requirements.py`:重新推导并逐关比对落表值(容差 ±0.5%),接入 RC——
  波次/经济数据一改,忘了重新生成就红灯

GDScript 侧 `get_recommended_power_for_level()` 只做查表+映射,不含模型。
删除:`RECOMMENDED_POWER_TARGET_MULT`、`_reference_on_pace_standing_power()`(上一版口径,整体作废)。

## 3. 救济阈值与文案新语义

- `loadout_power_ratio = 玩家战力/推荐`,语义为"相对固定通关线的余量"
- **< 1.0**:目标面板提示"低于本关通关线,可能守不住防线"(中英文入 localization)
- **∈ [0.85, 1.0) 且 level_ordinal < 50**:早期兜底 +8% 基地血量(帮压线玩家挤过去;
  低于 0.85 模型判定救不回来,不再假装能救)——带宽用探针实测后定稿,此为初值
- 结算/配装只显示同一个“战力 / 推荐”；局内选卡完成度另列为事实文案，不折算成第二个战力。
