# 战力 4.0：真实漏怪防线标定（2026-08-16）

## 1. 这次修的是什么

Owner 在 `level_080` 实测使用火焰少年、终焉炼狱炮、熔星重甲、恒星熔炉核心与不灭机凰通关，但出战页显示 `有效战力 684 / 推荐 926`，并给出“严重不足”。复算确认 684 完全由旧防线轴产生：旧模型仅按推荐等级套一条三次方曲线，得到 `line_capacity=5.2955`，没有读取本关究竟会有多少敌人真正接触基地。

本轮不改敌方 HP、伤害、波次、Boss 数量、星级门槛或战斗结算；只更换战力合同里的防线口径，并保持玩家只看到一个“有效战力”。

## 2. 4.0 公式

推荐刻度 `P_rec` 仍是关卡固定值，不随存档、装备或所选关卡之外的状态变化。三轴最终仍取最短板：

```text
有效战力 = P_rec × min(R_crowd, R_boss, R_line)
```

清群与 Boss 两轴沿用已验收的真实 HP、机制时间、属性弱点 / 抗性和保守选卡投影。防线门槛改为：

```text
预计承伤预算 = 参考基地生命 × (1 - 二星剩余生命阈值)
防线需求 = max(0.25, 同源模拟器预计漏怪伤害 / 预计承伤预算)
原始防线比 = 玩家防线容量 / 防线需求
```

Boss 关的参考基地生命继续包含战斗模拟器已使用的 Boss 关生命缓冲，不另造一套常数。合同同时落盘 `line_expected_breach`、`line_base_hp`、`line_target_hp_ratio`，因此 CI 可逐关验证数据与模拟器同源。

输出越高，敌人与基地接触时间通常越短，但不能把高输出无限重复计入生存。4.0 只允许一个按小怪 / Boss HP 份额加权的有限修正：

```text
pressure = mob_share / R_crowd + boss_share / R_boss
接触时间修正 = clamp(pressure ^ -0.5, 0.85, 1.15)
R_line = 原始防线比 × 接触时间修正
```

即使输出极高，防线轴最多只加 `15%`；输出不足时最多扣 `15%`。这避免“高攻被旧防线曲线永久封顶”，也避免把输出第二次无限放大成防御。

## 3. level_080 复算

截图装备保持不变，仅改变永久技能等级。当前关卡推荐刻度仍为 `926`，因为真实关卡压力未变；修正的是原先错误压低玩家有效战力的防线判断。

| 永久技能档 | 有效战力 / 推荐 | 比值 | 短板 | 结论 |
|---|---:|---:|---|---|
| L1 | 902 / 926 | 0.974 | Boss | 兜底带，有压力但可过，不再“严重不足” |
| L2 | 1037 / 926 | 1.120 | Boss | 正常可通关 |
| L3 | 1157 / 926 | 1.249 | Boss | 稳定优势 |
| L4（80 关节奏档） | 1626 / 926 | 1.756 | Boss | 明显优势 |
| 全部 L5 | 4482 / 926 | 4.840 | 防线 | 毕业后碾压，有限修正已封顶 |

低等级、无护甲 / 芯片 / 宠物的反例仍只有 `110 / 926 (R=0.119, Boss)`，严重预警仍成立。4.0 不是降低警告阈值，也不是把所有构筑放行。

## 4. 全战役与冻结锚点

- 本阶段验收时 `level_099` 最强免费毕业构筑为 `2724 / 2340, R=1.1643, 短板 Boss`。阶段 186 经 Owner 批准改为同型号固定 Boss 耐久 + 数量编队后，绝对刻度与完整阵容锚点由 `design/35_fixed_boss_identity_and_rosters.md` 接管；防线公式本身未回退。
- `level_085` 半速反向构筑为 `R=0.4850`，仍明确低于通关线。
- 2–98 关节奏族走廊共 97 关，实测 `R=[0.9700, 1.3800]`；短板分布为清群 83 关、Boss 14 关，没有关卡再由脱离真实漏怪量的等级曲线制造防线短板。
- `level_055` 的旧 `R≈0.943 / 防线` 快照在本轮正式退役：该锚点建立于旧硬免疫、旧幽影 HP 与旧三次方防线合同。当前 Boss 已改为百分比抗性且幽影生命已下调，继续强钉旧失败结果会把已修复的真实战斗倒逼回错误显示。
