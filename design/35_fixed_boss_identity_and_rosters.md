# Boss 固定身份耐久与数量编队（2026-08-16）

## 决策

同一个 Boss 模型在普通战役中必须有稳定、可学习的生命/装甲、抗性、弱点和特殊机制。关卡越后不再把同一张 Boss 模型暗中乘成不同血量，而是通过玩家能直接看见的数量、通道和错峰时间抬高压力。

- `bosses.json.fixed_hp` 是单只 Boss 的完整总耐久。
- `armor_hp_ratio` 从该总耐久中拆出装甲，不额外加血。
- 普通战役固定 Boss 不乘 `difficulty_coef`、`base_hp_ref`、晚波 Boss HP、局内技能压力、`boss_hp_level_bonus` 或 `boss_survival_hp_ramp`。
- 挑战与无尽保留各自明确的模式倍率。
- `waves[].boss` 是主 Boss；`runtime_bosses` 是同一波的额外 Boss，必须明写 type / lane / interval。

## 推荐战力口径

推荐战力和玩家有效战力必须共同消费完整 Boss 编队。原先按 Boss ID 聚合后再判断“主 Boss”的逻辑会把 4 只相同 Apex 误认成 1 只，现改为按 wave 主行单独计算 primary，额外三只形成明确的 `runtime_boss_pressure_mult=4.0`。因此绝对显示刻度会变化，但通关判断继续使用清群 / Boss / 防线三个比值的最短板。

当前关键结果：

- 99 关满级免费毕业族：`5322 / 4546`，`R=1.1707`，短板 Boss。
- 80 关 Owner 截图构筑（永久技能 L4）：`4268 / 2431`，`R=1.7558`，短板 Boss。
- 2–98 关节奏走廊：`R=[0.9700,1.3800]`。
- 99 关散弹枪毕业族全程模拟约 `393.9s`，低于 `460s` 上限；只计四 Boss 的真实运行时矩阵约 `183.0s`。
- 四只 Apex 每只始终为 `84.00M`，最快免费反制单只约 `45.7s`，不会因出现关卡改变。

## 回归护栏

- `validate_data.py` 要求所有 Boss 有正数 `fixed_hp`。
- `check_clear_requirements.py` 重新派生 99 关合同，并冻结 80 / 99 关的当前结果。
- `check_endgame_balance.py` 锁定 Apex 在 85 / 90 / 95 / 99 关为 1 / 2 / 3 / 4 只、每只 HP 完全相同，以及最终免费毕业族时间窗。
- `m1_smoke_test.gd` 锁定普通 Boss 固定耐久、挑战显式倍率、最终四只同型号编队、装甲拆分与抗性语义。
