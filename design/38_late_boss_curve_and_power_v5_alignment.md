# 后期 Boss 难度曲线与战力 5.0 对齐

日期：2026-08-20
状态：已实施，取代阶段 194 中“战役同型 Boss 折减”和旧战力 4.0 的后期标尺。

## 一、实测问题

Owner 在 `level_085` 使用火焰少年 Lv40、终焉炼狱炮 Lv50、熔星重甲 / 恒星熔炉核心
Lv35 和炮塔无人机 Lv15 时，界面显示“有效战力 1885 / 推荐 1261”，实际仍在 1:24 被破线。
复盘显示这不是单纯把推荐数字整体上调就能解决：

1. `level_084 → level_085 → level_086` 的普通关总耐久出现尖峰后立即回落；尖峰几乎全部集中在
   一只提前登场的终局 Apex Boss 上，而不是来自可读的波次或数量变化。
2. 旧战力把面板弹道、穿透、连锁和永久技能收益当作可完全兑现的产能；真实 Godot 碰撞回放中，
   贴线目标、Boss 单体和密集尸潮的实际命中转化率明显不同，尤其高估 Boss 轴。
3. 关卡合同既把追加 Boss 计入 Boss 容量，又在最终“推荐战力”标题上再次乘数量修正，形成重复计价。
4. 战役同型 Boss 使用隐藏的第 2 / 3 / 4 只 HP 折减，同一个模型在不同关卡耐久不一致，玩家无法
   从模型、血条和数量形成稳定预期。

因此，`1885 / 1261` 不是“玩家以 1.49 倍战力仍失败”，而是旧标尺同时高估玩家真实输出、低估
关卡单体短板后产生的错误比较。

## 二、Owner 批准的修复原则

- 同一种战役 Boss 使用同一份 `fixed_hp`；难度通过数量和 Boss 种类升级表达。
- 85 关不再提前塞入一只终局 Apex；70–99 关形成可读的“同型数量阶梯 → 更高阶种类阶梯”。
- 有效战力与推荐战力使用同一套真实碰撞产能标尺；推荐标题不再重复乘 Boss 数量。
- 80 关压力通关回放冻结为 `R=1.05`，99 关毕业战冻结为 `R=1.16`。冻结的是实战语义和短板，
  不是旧显示数字。

## 四、战力 5.0

### 4.1 真实碰撞产能

新增可复跑生成器 `tools/generate_weapon_power_profiles.py`。它读取已纳入仓库的 Godot 物理武器
碰撞基准和既有付费 / 元素武器 DPS 审计，生成：

`economy.power_ruler.weapon_runtime_axis_calibration[weapon_id].crowd / boss`

玩家侧 GDScript 与 Python 合同生成器都只读该表。每把武器仍保留自身面板、人物、芯片、宠物、
永久技能与局内卡收益，但清群 / Boss 两条轴先乘真实命中转化，不再把理论弹道收益当成百分百命中。
生成器已接入 Release Candidate stale check，数据和实现不能静默漂移。

### 4.2 同尺比较

最终显示继续遵循三短板模型：

`有效战力 = 推荐战力 × min(清群比, Boss比, 防线比)`

Boss 数量、抗性、弱点和阶段机制只进入 Boss 容量合同一次。推荐战力标题直接来自合同基准，不再
二次乘追加 Boss 系数。80 / 99 两个真实回放只校准其观测到的 Boss 短板轴：

- `level_080`: `1038 / 989 = 1.05`，Boss 短板；
- `level_099`: `1667 / 1437 = 1.16`，Boss 短板。

全关卡按节奏走廊仍为 `R=[0.9700,1.3800]`。这代表 `R≈1.0` 是“有压力、通常能过”，而不是
无视克制、卡牌选择和操作结果的胜负保证。

## 五、回归结果

- 普通模式星级：`13×3★ / 86×2★ / 0×1★`；挑战无不可胜关。
- 2–98 关战力走廊：`[0.9700,1.3800]`。
- `level_085` 推荐战力：`1109`，不再出现旧 Apex 单体压力尖峰。
- Apex 单体理论相位合同：`116.6s`，未改。
- 99 关四只完整 Apex：毕业散弹枪族 `183.1s`，仍在 `[150,185]s`。
- 同推荐战力的物理毕业构筑：`357.3s`，仍低于 `460s` 战斗上限。
- 战力 5.0 的实测 Boss 轴同步用于无尽预算生成：第 `7–10` 轮用 `2%` 小桥接维持
  预算单调，第 `11–20` 轮线性接力至毕业参考；中期档撞墙第 `11` 轮、毕业档覆盖至
  第 `20` 轮，原批准生存带和 `68/78/89/100s` 目标均未放宽。

冲突，以本文和当前数据合同为准。
