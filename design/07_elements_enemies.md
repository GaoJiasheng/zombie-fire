# 07 · 元素克制 · 20 僵尸 · 8 Boss

## 1. 元素克制系统

5 元素：`physical 物理` / `fire 火` / `ice 冰` / `lightning 雷` / `poison 毒`。

不做复杂的环形相克，而是**每个敌人挂“弱点/抗性”标签**（简单、可读，符合“看得懂”支柱）。核心原则：**弱点是推荐解，抗性是阻力；任何合法伤害属性都必须能造成伤害，不设属性或物理硬免疫**。

| 关系 | 倍率 | 含义 |
|---|---|---|
| 弱点 weakness | ×1.5 | 该元素打它更疼 |
| 普通 normal | ×1.0 | 无修正 |
| 抗性 resist | ×0.5 | 该元素打它半伤 |

每个普通敌人可有 1 个弱点 + 0~1 个抗性；Boss 使用 `resistances` 记录每种属性的减伤百分比，当前标准抗性为 `0.5`（减伤 50%），弱点统一读取 `economy.weakness_mult=1.5`（增伤 50%）。关卡选择、Boss 登场、Boss 血条和命中反馈必须明确显示弱点加成或抗性减伤。
关卡选择界面**明示当关主要威胁与推荐弱点**（参考《向僵尸开炮》"关卡标注弱点"），让玩家赛前配元素；但非推荐元素仍可通关，只是更难满星。

元素附带效果回顾（详见 `05`）：火=灼烧DoT、冰=减速/冻结、雷=连锁/麻痹、毒=叠层DoT(可按%最大生命)、物理=无附带但稳定通用，少数特殊 Boss 会要求物理输出窗口。

### 威胁标签 `threat_tag`

敌人额外标注目标优先级标签，驱动自动瞄准、追踪弹、宝宝 AI 和 HUD 标记：

| 标签 | 说明 | 示例 |
|---|---|---|
| `breach` | 高近线威胁，到达防线后会快速攻击基地 | runner / charger / berserker |
| `support` | 给敌方加速、护盾、复活 | screamer / necromancer / warden |
| `burst` | 自爆或短时大伤害 | bomber |
| `tank` | 高血/吸火力 | brute / juggernaut |
| `window` | 有输出窗口或虚化窗口 | phantom / void_phantom |

设计意图：
- 8 个 Boss 系统性覆盖五元素抗性、破甲、相位、再生和多阶段机制，构成完整的 build 检验，但不会把任何已投入的合法构筑直接判为零伤害。
- 抗性统一解释为百分比减伤，弱点统一解释为百分比增伤。数值必须在 Boss 血条与命中反馈中可见，不能只写“弱火焰”却让玩家无法判断实际倍率。
- `armor_hp_ratio` 从 `fixed_hp` 的总耐久预算中切分装甲 / 本体，不在原生命外额外加血。装甲与本体分别显示血条；无穿透先扣装甲，`伤害穿透` 按当前比例越过装甲直击本体。
- `boss_void_phantom` 的相位是短时闪避窗口，不是属性免疫，并以较低生命换取高机动；`boss_apex_overlord` 鼓励物理主轴，但四种属性路线仍保留 50% 实际伤害。
- 同一个 Boss 模型在普通战役的每次登场都使用完全相同的 `fixed_hp`；普通难度不会再乘关卡系数、晚波倍率、局内卡压力或旧 Boss 生存曲线。重复关卡用 `runtime_bosses` 明写 2 / 3 / 4 只、分通道错峰入场。挑战 / 无尽仍可按模式的显式倍率调整，这是模式差异而不是同一普通关暗增血量。
- Boss 关均含前置普通波次铺垫，再进入 boss wave（见 `08`）。

## 4. 精英怪机制

普通波次中会出现**精英版**（词缀强化的普通僵尸）：
- 视觉：描边发光（见 `11`），体型略大。
- 数值：HP/伤害提升，掉落更多金币与 run_xp。
- **击杀精英额外触发一次局内三选一**（见 `03`），是节奏与战术高点。
- 词缀示例：迅捷（更快）、坚韧（更肉）、剧毒（死亡毒云）、护盾（自带护盾）——复用机制资产，低成本扩展难度。
