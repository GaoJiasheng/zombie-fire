## 1. 产品定位

第四套不是前三套的同级换色，而是**通关后的毕业型收藏与强度目标**：

- 视觉上是四套里质量、动画层级和情绪价值最高的一套。
- 数值上采用高成长：1 级只比正常同槽装备高约 `20%–30%`，满级才抵达约 `2.00x` 的最终属性。
- 解锁在战役完成之后，因此不把免费主线变成付费跳关；主要价值落在无尽、挑战、满配构筑和重复游玩。
- 它明确拥有最高综合上限，不伪装成与前三套完全平级；前三套仍保留火焰爆燃、冰霜控制、雷霆连锁的独立战斗体验。
- 不因为第四套更强而提高免费关卡敌人攻击、推荐战力或付费门槛。

一句话定位：

> **通关不是结束，而是黄金律开始生效。**

## 3. 视觉总纲：黑是舞台，金是运动

### 3.1 色彩比例

- `74%`：蓝黑、镜黑、黑曜陶瓷、暗枪灰。
- `18%`：暖金、拉丝金、微弱香槟金。
- `8%`：白金高能核心与极少量高光。
- 大面积主体禁止直接填纯黄或纯金；远看先读出黑色剪影，再读出流动金线。

### 3.2 金的三层运动

1. **慢层**：人物 / 基地背后的宽幅丝带，0.8–1.6 秒完成一次舒展，负责气势。
2. **中层**：围绕枪械、敌人或护盾的轨道金线，0.25–0.65 秒完成一次结构变化，负责机制可读性。
3. **快层**：子弹尾迹、命中飞丝和微粒，0.06–0.22 秒完成，负责开火手感。

三层不得全部同亮度。白金核心只占最小面积，外围鎏金逐级减亮，避免整屏泛黄。

### 3.3 材质语法

- 主体：镜黑陶瓷、黑色枪钢、缎面碳纤维、黑玻璃。
- 骨架：细拉丝金、少量镂空金属梁，不做厚重金砖。
- 能量：半透明液态金 / 光墨 / 丝带，不做火焰、雷电、冰晶或彩虹霓虹。
- UI：黑玻璃正文面 + 低亮拉丝金骨架；按钮的光效必须服务文字。

### 3.4 禁止项

- 禁止“黑甲加一圈金边”的低成本换色。
- 禁止埃及纹样、皇冠堆砌、中世纪王座、金币、奢侈品牌感。
- 禁止把金做成炼狱橙火、霓虹电弧或极地水晶。
- 禁止人物前方的大翅膀、浮枪贴纸、枪手分离、头脚裁切。
- 禁止用超量 Bloom 掩盖素材细节。

- `ZOMBIE FIRE` 使用深黑立体字面、细金切边、中央白金棱柱。
- 两条金色丝带从 Logo 后方绕过，不能盖住文字。
- 首页继续使用有效像素裁切后的 1040×500 展示框，不允许因源图留白再次缩小。
- 满级黄金律可在装备展示页使用独立“日蚀核心”徽记；首页主题 Logo 不随装备等级频繁变化。

### 5.2 控件

- 长按钮、短按钮、方形槽位、圆形技能键分别原生制作，不拉伸。
- 默认态金线亮度约为开火特效的 `25%`；按下态沿边框流过一次，不做持续跑马灯。
- 文字区保持近黑纯净面，不能让纹理穿过字号笔画。

### 5.3 基地

- 主体仍是工业防线，不变成宫殿。
- 黑色防线框架内嵌细金能量骨架；受击时金线向缺口汇聚。
- 护盾展开是“金丝织幕”，不是完整黄色圆顶。

### 5.4 八把免费武器

- 只换材质、流光遮罩和开火签名，不改变免费武器 ID / 数值 / 轮廓功能。
- 枪管保持深黑，金色流光仅在弹仓、能量管、准星和真实枪口附近移动。
- 终焉·黄金律武器保留独立模型，不被主题免费涂装覆盖。

## 6. 终焉·黄金律四件套

### 6.1 天衡裁决炮

- 物理 / 质量驱动定位，补齐第四角色钢铁先锋的毕业武器，但四名角色均可装备。
- 外形是长枪管重型质量炮与受控旋转机匣的组合；双手真实握持，枪托抵肩。
- 普通弹是细窄白金核心，周围两到三股金丝沿弹道旋转；不能读成雷电。
- 连续命中积累“裁决刻度”；满刻度触发一次有冷却的日蚀冲击。

### 6.2 永夜王铠

- 提高基地生命、减伤与受击后的有限修复。
- 累计有效受击后编织一次金丝护幕，并向上释放防线反击。
- 不提供无敌、永久护盾或无限回血。

### 6.3 黄金律核心

- 提高物理伤害、暴击质量、穿透后的余量转换和裁决积累效率。
- 只强化已发生的合法命中；不让普通一级子弹凭空获得弹射 / 溅射。

### 6.4 鎏金天隼

- 机械隼从基地后方起飞，优先跟随手动锁定目标，其次选择最高威胁。
- 投下短寿命“天衡标记”，提高对目标的稳定输出并给基地恢复少量结构值。
- 飞行动画使用黑色机械主体和细金光羽，不做火凤凰或极光鸟换色。

### 6.5 套装协同

- 2 件：裁决积累更稳定，护甲织幕冷却略缩短。
- 4 件：日蚀冲击后展开一次有限持续的“黄金律场”；场内金丝自动连接真实命中目标。
- 所有二次伤害 `generation_limit = 1`，不能递归触发新日蚀或无限连锁。
- Boss 保留技能展示时间；通过提高持续输出与压制稳定性获得强度，不用秒杀演出来体现付费价值。

## 7. 顶级战斗表现

完整表现至少包含：

1. **蓄能**：两条宽幅液态金丝在人物背后舒展，枪膛出现小面积白金核心。
2. **主射**：白金弹芯向上，金丝螺旋尾迹；人物和枪械后坐同步。
3. **命中**：目标点先出现黑色日蚀核心，再向外释放精确金环和书法飞丝。
4. **持续状态**：细金轨道贴着敌人身体绕行，不覆盖敌人类型、弱点和血条。
5. **击杀**：目标碎成少量黑屑，金线收束回弹道方向；不做整屏金爆。
6. **宠物**：天隼掠过目标，金色光羽只沿真实飞行方向脱落。
7. **护甲反击**：基地先织成半透明金幕，再由下向上释放聚焦波。
8. **主动技能联动**：四角色主动技保留原属性身份，外围增加黑金“授权环”，不把火 / 冰 / 雷全部染成金色。
9. **满级觉醒**：战场短暂降为深黑层，数条巨大鎏金轨迹从人物背后穿越战场；人物、枪口、敌人和危险区域必须仍可读。
10. **音触觉**：低频机械蓄能、短促金属谐振、干净白金命中；觉醒只使用一次中等触感，不连续强震。

减少特效模式保留弹道方向、日蚀核心、状态环、护幕和危险半径，只删除外围飞丝、星尘和第二层光晕。

## 8. 高成长数值口径

Owner 原话拆成两个不可混淆的验收层：

### 8.1 单槽最终属性

- 1 级：相对同槽最强免费 1 级基线，主要攻击 / 防御属性为 `1.20x–1.30x`，中心值 `1.25x`。
- 满级：相对同槽最强免费满级基线，**武器主要攻击贡献 `2.00x`，护甲综合防御贡献 `2.00x`**。
- 芯片、宠物和套装机制从同一总预算中拆分，不能每件各乘 `2.00x` 后再指数叠加。

建议成长曲线使用后置增长：

`multiplier(t) = 1.25 + 0.75 × t^1.65`，其中 `t` 为 0–1 的等级进度。

| 等级进度 | 建议倍率 |
|---:|---:|
| 0% / Lv.1 | `1.25x` |
| 25% | `1.33x` |
| 50% | `1.49x` |
| 75% | `1.72x` |
| 100% / 满级 | `2.00x` |

### 8.2 满配实际表现

正式实现必须用真实满配公式审计：人物 Lv.40、武器 / 护甲 / 芯片 / 宠物满级、永久技能满级、局内 16 技能合法满层，并计入射速、暴击、散射、多弹道、穿透、状态、宠物、护甲反击和套装伤害。

建议验收带：

- 加权实际总输出：最强免费物理满配的 `1.90x–2.05x`。
- 有效防御贡献：最强免费防御满配的 `1.90x–2.05x`。
- Lv.1 实际总输出 / 防御：对应免费基线的 `1.20x–1.30x`。
- 不允许攻击 `2x`、护甲 `2x`、芯片 `2x`、宠物 `2x` 分别相乘成失控结果。
- 不调整免费战役敌人攻击补偿付费强度；黑金解锁时主线已经完成。

“最终属性两倍”因此既会显示在装备详情的最终数字中，也会经过真实构筑审计；不会只靠隐藏倍率或漂亮文案宣称。
