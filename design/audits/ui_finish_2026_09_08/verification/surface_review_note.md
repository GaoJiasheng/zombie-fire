# UI-11 目视补验记录

全量 `final01` 开始后，目视发现霓虹暂停页三个动作的可见边框高度/中心不一致，退出键下缘像双框。虽然这些截图 issues=[]，本批已主动中止，不用作最终验收。

定位分两层：

1. 原 TextureButton 和九宫格子面板都在绘制。改为由纹理子面板独占可见表面，父节点保留原纹理、状态、modulate 与输入契约；切换回其他主题恢复原材质。此步消除了很淡的底图叠画，但目视偏移并未完全解决。
2. 真正影响可见框中心的是原图几乎透明的导出残像。以 512×160 档为例：primary 的 alpha 非零边界 y=6…149，但 alpha>8/255 的可见主体 y=41…131；secondary 对应为 y=5…137 与 y=38…131。直接 get_used_rect 仍把不同高度的空白当作框体。

最终按 alpha≥0.04 测量可见边框，加 2 个源像素辉光余量；结果缓存于每个纹理路径。未替换原图、未改字号/触摸区域/颜色规则。不是放宽任何检查阈值。

`pilot06`：仅消除叠画，12张中英三尺寸通过但目视仍偏。
`pilot07`：消除叠画＋真实可见框，12张中英三尺寸通过；原生目视确认暂停三键高度/中心一致、主菜单 Start 主次层级恢复。

最终全量复拍使用新批次 `final02`，不混用前一版本证据。
