# 火焰 / 冰霜 / 电系主动技能调优

基线：`db3eb7a5`。测试日期：2026-09-26 至 27。先锋、普攻亲和/碎冰、武器、敌人、关卡、冷却与全局战力公式均未修改。

## 调整与理由

- 火焰：主动基础倍率 2.4 → 1.8，保留局部大范围、4 段爆发及持续灼烧。只削伤害，不再同时缩小逻辑半径。
- 冰霜：保留开场寒潮、5 秒基础领域及原减速；领域每跳取原伤害 18%，开场寒潮取 50%。原本领域周期伤害远高于同级另外三人的整个技能，是本次主要收敛对象。
- 电系：首击不变；同次施法、同一目标第 n 击为 `max(0.25, 0.72^(n-1))`。在高威胁候选中优先未受击/少受击者，每次施法独立计数。保留雷击次数与清群能力，减少对一个 Boss 的整串满额轰击。
- 同步中英技能说明；纠正冰/电技能升级说明中原本写成 +10% 的 +12% 数据，以及电系 Lv2/4 实际各增加两次雷击（目标数与额外雷击各贡献一次）。

## 实战对照：32 对，而不是只挑胜利

使用既有 progression fixture，**仅替换角色**；相同装备、等级、种子（1103/2207）、Tier B、v2 卡牌策略。测试 001 / 005 / 010 / 099；这些配装不是每位角色的最优元素配装。

- 先锋 8/8 的完整结果对象逐位一致（含伤害、耗时、选卡、波次），不是仅通关一致。
- 四人普通 099 均保持 2/2 通过，共 8/8；不是全 99 关十种子验证。
- 整组胜利由 27/32 → 26/32。旧版本就有 5 个失败样本（火焰 005 两种子、010/1103；电系 005 两种子），不归为本次新增失败。
- **新增失败**：火焰 010/2207，原 163.38 秒通关/47.8% 防线，新 123.17 秒失败。表示此固定物理配装在削弱后不再足够，不能声称前期全部无回归；本次没有通过改怪物、降低关卡要求或加回隐藏伤害掩盖它。
- 冰霜 010 两种子由 110.55 / 109.68 秒 → 132.60 / 129.42 秒，仍满血通关；099 由 365.72 / 327.37 秒 → 406.80 / 411.68 秒，仍通过。
- 火焰 099 两种子由 282.83 / 266.08 秒 → 283.75 / 264.55 秒，仍通过。真实整关受选卡/过量伤害/敌人位置影响，不应将技能减伤直接乘到通关耗时上。
- 电系 010/2207 防线由 95.9% → 55.3%，仍通过；削弱单体雷击确实增加 Boss 压力。

原始完整战报见 `evidence/before_campaign.json` / `evidence/after_campaign.json`。不改关卡不代表所有既有弱配装仍能过；先锋对照保持可过。是否进一步补偿火焰早期物理配装，是下一轮手感决策，不应借机重标整个战役。

## 动画审阅与修正

保留既有素材，不重生资产，不改变命中时点/技能时长来迁就动画。使用真实渲染器按 0.1/0.3/0.6/1/2/4/5.5/7 秒取帧，三角色怪群 1×/5× 前后对照，补充最终 Boss 1×；720×1560 输出对应 1080×2340 高屏布局。

1. 火焰：去掉第一次实际命中前的完整大爆炸，改为小点火提示；爆炸尺寸随每段实际半径变化，减少飘转/额外火花，震屏由 5–10.4 收至 2–3.2。
2. 冰霜：移除每跳在空地/基地上方反复出现的大冰晶；每道寒潮由五簇减为三簇，减小尺寸/透明度；领域持续状态由敌人冰霜光环和小命中特效承载，不遮满战场。
3. 电系：移除空地上的起手巨型雷电；电弧连接上次实际命中点与本次目标，命中闪光随重复伤害收敛；每三击轻微震屏一次，不再每击强震。
4. 三人的角色开场特效缩放 1.2 → 0.78，透明度 0.92 → 0.65，避免高倍速下盖住角色；保留不随倍速压缩的招式辨识演出。先锋保持原值。
5. 冰/电技能复用普通命中去重，避免招式效果和通用命中再次叠成白团；弱点/护盾/抗性等专用反馈仍保留。减弱闪烁/震动继续走原设置链。

人工检查重点是人物、敌人轮廓、血条与目标归属；不是 iPhone GPU 性能认证。仍有受击高光与伤害数字，刻意保留命中强度，不做完全消光。最终截图见 `evidence/*-final.png`，全部时点临时原图在 `/tmp/signature-visual-final-*`。
