# 本轮文案与数值展示对照

没有精简或重写技能、商品、隐私说明，也没有改变技能或装备实际数值。

| 场景 | 中文 | English | 说明 |
| --- | --- | --- | --- |
| 未解锁角色被动 | 「已生效：…」→「解锁后：…」 | “Active: …” → “After unlock: …” | 只修正当前状态前缀，保留后续完整技能介绍。 |
| 未解锁角色选定 | 禁用「选定」，提示「尚未解锁」 | Disabled Select, existing Locked tooltip | 选定失败不关闭详情；角色专属技能独立升级规则保持不变。 |
| 未拥有芯片详情 | 「当前加成」→已有「解锁后加成」 | “Current Bonus” → existing “Bonus After Unlock” | 使用已有的状态文案，不创造新的解锁条件。 |
| 英文结算 | 中文原样 | Hero name + “Defense Complete” / defeat outcome | 原来的中点改为换行，保留原句所有词，不缩字号。 |
| 芯片小幅升级 | 「下一级 +0%」→例如「下一级 +0.34%」 | “Next Level +0%” → e.g. “Next Level +0.34%” | 不足 1% 的非零变化保留两位小数。 |
| 技能百分比 | 1.2 → 120% | 1.2 → 120% | 根据字段单位格式化；3、4、5 弹道仍是整数，不乘 100。 |
| 已升级装备摘要 | 摘要显示当前等级的生命倍率／加成 | Summary displays current-level HP multiplier / bonus | 与详情已有成长展示共用公式，没改战斗、战力、养成成本。 |
| 屏障数量 | 固定「+1」→读取配置 | Hardcoded “+1” → configured count | 黄金护甲展示为 +2，与其详情／配置一致。 |

隐私的内购承诺、真机支付错误措辞、技能历史开发说明未改，留待 Owner 对语义拍板。
